Game Development with Unity & C#

Description

A set of projects in 3D game development using the popular Unity engine and the C# programming language. These projects focus on different aspects of game development, including player behaviour scripting, physics, enemy AI, and user interface design.

Games Developed

A physics simulation of billiards focused on ball interaction and collision calculations.

Shooter Game (Counter Strike)

A first-person shooter prototype featuring player movement, shooting, and simple enemy AI.

Crazy Ball

A platformer built around steering a ball through varied obstacles, focused on level design and precise control.
